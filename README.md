# Ordinary Differential Equations

This repository contains the LaTeX source files for the **Ordinary Differential Equations** course notes.

- `Ordinary Differential Equations.tex`: the main document, including document settings and chapter entries.
- `Chapters/`: the source files for individual chapters.

## Build

Install a recent full TeX Live distribution with XeLaTeX. From the repository root, run:

```sh
xelatex -interaction=nonstopmode -halt-on-error "Ordinary Differential Equations.tex"
xelatex -interaction=nonstopmode -halt-on-error "Ordinary Differential Equations.tex"
```

PDFs, original board photographs, temporary files, and build artifacts are excluded from version control.

## Contributing

Typo fixes, mathematical corrections, and typesetting improvements are welcome. The notes will be updated as new chapters and corrections become available.
